# Чунявая Бруня — вход для нового диалога

Самостоятельная игра, выделенная из BlockTurn. Сначала читай этот файл и README.md, затем файлы по задаче. Правила — docs/RULES.md.

- Все Node/npm, проверки и сборки — только Docker. `./scripts/check.sh` проверяет тесты и TypeScript.
- Локально: `docker compose up -d --build`, http://localhost:8089. Compose-проект `brunya`.
- Публикация: main → GitHub Actions → https://itsokbear.github.io/block-turn-chb/. Проверить Pages-сборку командой из README, затем коммит и `./scripts/publish.sh`. Дождаться успешного Actions для своего SHA.
- Менять только запрошенное. Для визуальных правок не менять баланс, жесты, сохранения. Для логики добавлять осмысленные тесты.
- `.deploy/` и `.local/` исключены из Git и Docker. Не читать/печатать приватные ключи, не копировать ключ из BlockTurn, не коммитить эти каталоги.
- Проверять визуальные правки в графическом браузере на мобильной ширине. Не заявлять проверку на физическом iPhone без неё.

## Карта

- `lib/serpent.ts` — ход Бруни, две очистки, линька, риск.
- `lib/game.ts` — общая геометрия, выдача, базовые бонусы и проверка формата игры.
- `lib/storage.ts` — независимые сохранения и восстановление.
- `app/page.tsx` — управление, меню, состояние. Только Бруня; выбора Classic/Serpent нет.
- `app/globals.css` — геометрия, управление, анимации; `app/desert.css` — пустынная тема; `public/desert.svg` — дюны.
- `app/snake-layer.tsx`, `app/bruni-art.tsx`, `app/shell-art.tsx` — Бруня и скорлупки.
- `lib/events.ts`, `lib/audio.ts`, `lib/drag.ts` — события, звук, относительный перенос.
- `app/pwa-status.tsx`, `lib/pwa-updates.ts`, `scripts/*pwa*`, `scripts/sw-template.js` — PWA.

## Не нарушать

- Бруня неуязвима, длина 6. Скорлупка = 6 / POOP. `won` оставлен для совместимости формата, победы нет.
- Реролл за 3+ линии, бомба за каждое 4-е комбо. Максимум по одному бонусу, на старте нет.
- Тап мгновенно вращает; анимация не блокирует быстрые тапы. Подавлять iOS selection/callout.
- Одна установка — один итоговый звук/overlay. Взрыв не выдаёт наград.
- Не переименовывать `brunya-game`, `brunya-best`. Никогда не записывать в ключи BlockTurn.
- Pages base path `/block-turn-chb`, локально пустой. Manifest, SW, фон и офлайн-ресурсы должны сохранять правильную область действия.
